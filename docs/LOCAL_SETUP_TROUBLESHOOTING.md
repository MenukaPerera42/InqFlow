# Local startup troubleshooting

Use the setup steps in [README.md](../README.md). Do not replace an existing `.env` or remove the PostgreSQL volume to fix a connection problem.

| Symptom                                          | Check                                                                                                                                                    | Resolution                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run dev` says a port is in use              | `lsof -nP -iTCP:3000 -iTCP:3001 -sTCP:LISTEN`                                                                                                            | Use the already running services or stop the known processes. The root script deliberately refuses to start a second copy.                                                                                                                                                                                                                    |
| Prisma `P1010` or seed access denied             | `docker compose ps`, `docker compose port postgres 5432`; compare the host port, username, database, and URL schema in `.env` without printing passwords | A separate local PostgreSQL may own 5432. Set `POSTGRES_PORT` and both database URLs to a free Docker host port, such as 55432. An existing Docker volume retains its original database password even when `.env` changes; changing that role password requires a deliberate data-preserving operation. Never reset the volume to solve this. |
| `SESSION_SECRETS` rejected                       | Inspect whether `.env` still contains `replace_with`                                                                                                     | Generate a value with `openssl rand -hex 32` and put it only in ignored `.env`. Rotating it invalidates existing sessions unless the old value remains as a comma-separated secondary secret.                                                                                                                                                 |
| Login fails after changing `SEED_STAFF_PASSWORD` | Check whether seeded users already existed                                                                                                               | Seeding leaves existing password hashes untouched. Use the original local password, or deliberately rotate the two development account hashes. Changing `.env` alone does not reset accounts.                                                                                                                                                 |
| Workspace shows a connection error               | Check API `/health`, browser network request to `/auth/me`, `NEXT_PUBLIC_API_URL`, API port, Docker health, and allowed `FRONTEND_ORIGINS`               | Start the API and database, then reload. Do not disable cookies, CORS, or Origin checks. The web and API origins must be same-site for the local cookie design.                                                                                                                                                                               |
| npm reports blocked install scripts              | Run `npm run db:generate`, `npm run build`, and tests                                                                                                    | npm 12 may block dependency install scripts. The explicit Prisma generation step is required. Review any proposed script approval package by package; `fsevents` is optional on macOS. Do not globally disable script protection.                                                                                                             |

Node 22 LTS is the recommended local runtime. The current checks also ran on Node 26.11.1, but this repository does not claim every upstream package supports that version. Keep `.env`, `.env.local`, and generated credentials uncommitted.
